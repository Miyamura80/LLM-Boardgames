Welcome to the docs! Follow these steps to bootstrap the Rust server + CLI template.

## Quick Start

import { Step, Steps } from 'fumadocs-ui/components/steps';

<Steps>
<Step>

### Build the workspace

Build and test the Rust workspace:

```bash
cargo build --workspace
cargo test --workspace
```

The optional frontend uses Bun: run `bun install` when you want to work on it.

</Step>

<Step>

### Configure Settings

Edit `crates/config/global_config.yaml` and override values with `APP__...`
environment variables (e.g. `APP__SERVER__PORT=9090`). Point a deployed binary
at its config with `APP_CONFIG_PATH`.

Sanitized configuration is exposed to the frontend over HTTP at
`GET /api/v1/config` (the `useConfig()` hook), and never carries secrets.

</Step>

<Step>

### Run the Application

Start the HTTP API, or invoke commands headlessly:

```bash
make run                       # = appctl serve (GET /healthz, /api/v1/commands)
appctl call ping --json        # invoke a command over the CLI
make dev                       # optional frontend; Vite proxies /api → appctl serve
```

</Step>

<Step>

### Run Tests

Keep the repo healthy with linting and tests:

```bash
cargo test --workspace         # Rust tests
cargo clippy --workspace --all-targets -- -D warnings
bun run check                  # frontend/TS lint & formatting via Biome
bun run knip                   # dependency linting
```

</Step>
</Steps>
